# Smart Student Helper

## 📌 About the Project

Smart Student Helper is a student-focused web application that helps students manage their academic activities in one place.

Students can manage their timetable, assignments, exams, projects and study tasks. The system helps prioritize tasks based on deadlines and importance.

## 🎯 Problem Statement

Students often struggle to manage assignments, exams, projects and study schedules. They may forget deadlines or have difficulty deciding which task to complete first.

## 💡 Proposed Solution

Smart Student Helper provides a single platform where students can organize their academic activities and receive smart task priorities and reminders.

## 👥 Target Users

- College Students
- School Students

## ✨ Key Features

- Student Login and Registration
- Personal Dashboard
- Timetable Management
- Assignment Management
- Exam Management
- Project and Study Task Management
- Smart Task Priority
- High / Medium / Low Priority
- Deadline Reminders
- Notifications
- Progress Tracking
